# SaudiKycApi
A lightweight ASP.NET Core 8 Web API &amp; dashboard designed to validate Saudi standardized formats in real time. Features 6 key verification engines: National ID/Iqama (Luhn algorithm), IBAN (ISO 7064 &amp; bank detection), National Address (SPL), ZATCA TIN, Commercial Registration, and Mobile provider detection. Fully dockerized with xUnit testing.
